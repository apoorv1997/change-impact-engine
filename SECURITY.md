# Security

Please do not open a public issue for a security problem. Report it privately through GitHub:
**Security → Report a vulnerability** on this repository. The maintainer aims to reply within a week.

Worth reporting, for example: a way for a repository being analysed to run code on the machine running aftershock, a leak
of `TYPESAFE_API_KEY` or other secrets into a report or PR comment, or a way around a spend cap.

Only the latest commit on `main` is supported.
