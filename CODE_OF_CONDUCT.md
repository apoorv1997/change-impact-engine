# Code of Conduct

aftershock follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, criticise code rather than people, and keep discussion on the work.
Harassment, personal attacks and discriminatory language are not accepted in issues, pull requests or any other project
space.

To report a problem, email the maintainer at the address on [their GitHub profile](https://github.com/apoorv1997).
Reports are read only by the maintainer and kept private. The maintainer may remove comments, close threads or block
participants who break these rules, following the Covenant's enforcement guidelines.
